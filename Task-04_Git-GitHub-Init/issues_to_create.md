# Suggested GitHub Issues

Create these as separate issues using the supplied bug and feature templates.

1. Add CSV export for filtered usage records — acceptance: export contains only the current search result and includes column headings.
2. Add configurable alert threshold — acceptance: changing the environment value updates both summary/alert results and tests.
3. Add pagination for large usage tables — acceptance: page navigation preserves the query and never loads every row at once.
4. Add email notification adapter — acceptance: sends only after explicit configuration and never logs credentials.
5. Add authentication and role checks — acceptance: unauthorized users cannot read or create usage data.
